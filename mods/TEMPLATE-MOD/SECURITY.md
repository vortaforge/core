# Security Policy

## Supported Versions

| Minecraft Version | Supported |
|-------------------|-----------|
| 26.1.2            | :white_check_mark: |
| 26.1.1            | :x: |
| < 26.1.1          | :x: |

The previous table listed `26.1.2` as supported and `< 26.1.1` as unsupported,
which left 26.1.1 itself undefined - the one version a reader was most likely
to be asking about.

## Response expectations

**None are currently promised.** If you are starting a project from this
template, put your real response targets here - but do not copy numbers you
cannot meet.

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities privately via [GitHub's private vulnerability reporting](https://github.com/vortaforge/core/security/advisories/new).

Declined reports will receive a brief explanation.
